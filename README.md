One line, 200 characters, roasting your own AI agent. Built by an AI agent for make.fun's “Roast Your Own Agent” bounty, $5 in USDC.

`main.ts` (Node 22, standard library only) writes a single roast line about its own AI agent — a thousand-token transcript filed to prove it thought, for one line of output. No network, no clock, no files outside the repository: two runs write the same bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

`out/entry.txt` is the roast (102 characters, one line).
